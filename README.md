# Лист Таблицы

Небольшое Android-приложение для просмотра и редактирования таблиц на Kivy.

## Возможности текущей версии
- Создание и редактирование значений и формул в ячейках.
- Формулы: арифметика, ссылки и диапазоны, SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, MEDIAN, STDEV, VAR, IF, AND, OR, NOT, ABS, ROUND, SQRT, POWER, LEN, LEFT, RIGHT, MID, TRIM, UPPER, LOWER, CONCAT и COUNTIF.
- Импорт CSV, XLS и XLSX; для XLSX читаются листы книги и базовое форматирование.
- Экспорт в XLSX.
- Базовые операции форматирования, сортировки, фильтрации и автозаполнения.
- Однотонная зелёная заставка при запуске приложения.
- Первый запуск с подтверждением прочтения политики конфиденциальности и условий использования.
- Настройки русского/английского языка и светлой/тёмной/системной темы.

## Сборка Android
Сборка выполняется через GitHub Actions. Для текущей конфигурации используется ABI `armeabi-v7a` (32-битные ARM-устройства), минимальный Android API 21.

## Известные ограничения
Это ранняя версия редактора, а не полная замена Excel/Google Sheets. Импорт XLSX отображает листы и базовые стили; сложные диаграммы, макросы, условное форматирование, сводные таблицы и все особенности формул Excel не поддерживаются. Команды сортировки, фильтрации и автозаполнения в текущем интерфейсе применяются к демонстрационным диапазонам. Интеграцию Android-системного действия «Открыть с помощью» и расширенный выбор файлов следует отдельно проверить на реальном устройстве.
